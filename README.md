# リニア×コネクト！

**LINEAR FUNCTION TRAINING** — 中学生向けの、比例・一次関数のグラフ読み取りトレーニング Web アプリです。
グラフと式の対応をテンポよく繰り返し、コンボ・スコア・段位を競いながら「傾き」と「切片」を読み取る力を鍛えます。

## 動作環境・起動方法

- `index.html` 1 ファイルで完結しています（HTML / CSS / JavaScript をすべて内包、外部ライブラリなし）。
- ブラウザで `index.html` を開くだけで動作します。ビルドやサーバーは不要です。
- スマートフォンのタッチ操作を主な対象としています（拡大縮小を無効化した縦画面レイアウト）。PC のマウス操作にも対応しています。
- 効果音は Web Audio API で合成しており、音声ファイルは使用していません。
- ハイスコアはブラウザの `localStorage` に保存されます。

## ゲームモード

### コネクトモード

表示された式（例：`y = 2/3 x + 1`）に合う直線を、座標平面上の格子点をタップして引きます。

- 座標平面は x, y とも −6〜6。タップ位置は最も近い格子点にスナップします。
- 2 点がそろった時点で判定し、2 点を通る直線が式と一致すれば正解です。
- 同じ点をもう一度タップするとその点を消去。3 点目をタップすると 1 点目を残して 2 点目を置き換えます。
- 「点を消す」ボタンで打った点をすべて消去します。

| 出題範囲 | NORMAL | HARD |
| --- | --- | --- |
| 一次関数 | 2 点をタップ | y 軸（x = 0）上の点はタップ不可（y 軸を赤く太く表示） |
| 比例 | 原点が固定済み。原点以外の 1 点をタップ | 原点は固定されず、原点のタップも禁止（赤い × 印）。原点以外の 2 点をタップ |

**むやみなタップへの警告**：1 問の中で不正解の判定が一定回数（比例 2 回、一次関数 4 回）に達すると「考えてから タップしよう！」と表示され、段位ペナルティが 1 加算されます。

### アンサーモード

表示されたグラフを見て、`y =` に続く式をボタンで入力します。

- 入力ボタン：分数（3/2, 2/3, 1/2, 1/3, 1/4）、数字（1〜4）、`+`、`−`、`x`、`←`（1 つ戻す）、`消去`（全消去）
- 入力の文法：`[符号] 係数 x [符号 数字]`。係数が ±1 のときは `x` だけで入力できます（`1x` も可）。
- ボタンを押すたびに判定し、正解になった瞬間に次の問題へ進みます。不正解の場合は何も起きず、入力を続けるか修正します。
- 分数は約分済みの形で答えます。
- 「ヒント」ボタンで 2 段階のヒントを見られます（[ヒント](#ヒント) を参照）。

| 出題範囲 | NORMAL | HARD |
| --- | --- | --- |
| 一次関数 | 方眼つきのグラフ。コンボが 5 の倍数に達した直後は**特別問題**（下記） | 方眼・目盛りなし。軸と直線に加え、切片と直線上の格子点 1 つを座標つきで表示 |
| 比例 | 方眼つきのグラフ | 方眼・目盛りなし。軸と直線に加え、原点以外の格子点 1 つを座標つきで表示 |

**特別問題**（アンサー・一次関数・NORMAL）：方眼と格子点を消したグラフで、x 軸・y 軸の両方と原点以外の整数座標で交わる直線が出題されます。正解するかコンボが切れると通常の問題に戻ります。

## ヒント

アンサー・コネクトの両モード、NORMAL・HARD、一次関数・比例のすべての組み合わせで使えます。答えそのものは表示せず、文章とグラフ上の補助表示で考え方を順に案内します（ヒントを見ても自動で正解にはならず、入力・タップは自分で行います）。

### 表示タイミングと操作

| プレイ時間 | ヒントボタンの出現 |
| --- | --- |
| 練習 | 出題直後から |
| 1分 / 3分 / チャレンジ | 出題から 12 秒後（その問題が表示されてからの時間で判定） |

- ボタンは「ヒント」→（タップ）ヒント① ＋「次のヒント」→（タップ）ヒント② ＋「ヒント表示中」（以降は押せない）と変わります。
- ボタンはアンサーモードでは `y =` の右、コネクトモードでは「点を消す」の右に表示されます。
- ヒントの文章はグラフの下のパネル（2〜3 行）に表示されます。
- 次の問題に進むと（練習モードでは「次へ」を押したとき）ヒントは消えます。不正解や「点を消す」「消去」「←」ではそのまま残ります。
- ヒント表示中もタイマーとコンボゲージは通常どおり進みます。
- ヒントを使ってもスコア・コンボ・段位にペナルティはなく、リザルト画面にも使用回数は表示されません。

### グラフ上の補助表示

| 表示 | 意味 |
| --- | --- |
| 黄色の点 | 注目する点（アンサーモード、比例 NORMAL の原点） |
| 水色に光る点 | タップする候補の点（コネクトモード） |
| 点線の円 | 参考点（HARD の切片・原点。タップはできない） |
| オレンジの矢印 | 横方向の移動（「右に〇」） |
| 緑の矢印 | 縦方向の移動（「上に〇」「下に〇」） |

ヒントで示す点は、出題中の式から計算した直線上の格子点（−6〜6 の範囲内）です。コネクトモードではタップできる点だけを候補にします（HARD 一次関数では y 軸上の点、比例では原点を候補にしない）。移動量は基本的に「右に 分母、上（下）に 分子」で、範囲の都合で使えない場合は同じ直線上の別の 2 点を使い、矢印と文章の移動量は常に一致します。

### ヒントの内容

| モード | ヒント① | ヒント② |
| --- | --- | --- |
| アンサー / 一次関数 | 切片（y 軸との交点）を強調 | 切片から別の格子点への移動量（右に〇、上／下に〇）と、傾きの求め方・符号のアドバイス |
| アンサー / 比例 | 原点と、直線上の別の格子点を強調 | 原点からその点への移動量と、傾きの求め方・符号のアドバイス |
| コネクト / 一次関数 NORMAL | 切片 (0, b) をタップ候補として案内 | 切片（または打った正しい点）からの移動量と、2 つ目にタップする点 |
| コネクト / 比例 NORMAL | 原点と、傾きの符号から進む向き（右に進んで上／下） | 原点からの移動量と、タップする点 |
| コネクト / 一次関数 HARD | 切片を参考点にし、そこから移動した先のタップできる点を 1 つ案内 | y 軸上以外のタップできる 2 点と、その間の移動量 |
| コネクト / 比例 HARD | 原点を参考点にし、原点から移動した先の点を 1 つ案内 | 原点以外のタップできる 2 点 |

- HARD のアンサーモードでは方眼を表示しないまま、もともと座標つきで表示されている点を使って案内します。
- コネクトモードでは、すでに打った点も考慮します。正しい点を打っていればそれを使ってもう 1 点を案内し、直線上にない点を打っていれば「今の点を消して、光っている点をタップしてみよう！」と打ち直しを案内します。ヒントが点を勝手に消したり動かしたりすることはありません。

## 出題仕様

- 傾き：50% の確率で整数 ±1, ±2, ±3, ±4、50% の確率で分数 ±1/2, ±1/3, ±1/4, ±2/3, ±3/2（±3/4, ±4/3 は出題しない）
- 切片：一次関数は −4〜4 の整数、比例は 0
- 直前と同じ問題は連続して出題しません。

## スコア・コンボ

- 1 問正解ごとの得点：`1000 + 100 × コンボ数`。一次関数はその 2 倍。
- 正解すると「正解！ ○ Combo!!」を 0.8 秒表示します（この間はタイマー・ゲージ停止、入力無効）。
- コンボが 5 の倍数のときは画面フラッシュとともにメッセージを表示：5「Great !」、10「Excellent !」、15「Marvelous !」、20 以上「Incredible !」

### コンボゲージ

- 1 問目（コンボ 0）ではゲージは減りません。正解するたびに満タンに戻り、減少を開始します。
- ゲージが空になるまでの時間：`(timeB × 2.6 + 1) 秒 ÷ 速度倍率`
  - 速度倍率：1分モードは `1 + 0.1 × コンボ数`、3分・チャレンジは `1 + 0.05 × コンボ数`
  - timeB は下表（段位計算と共通）
- ゲージが空になるとコンボが 0 に戻ります（チャレンジでは即ゲーム終了）。

## プレイ時間

| 種類 | 内容 |
| --- | --- |
| 練習 | 時間制限なしで好きなだけ解ける。スコア・コンボ・段位・ハイスコアはなし（ヘッダーには「練習モード」と表示し、タイマー・スコア・コンボ・ゲージは非表示）。ヒントボタンは出題直後から使える。正解しても自動では進まず、「正解！」のポップアップで「次へ」を押すと次の問題、「練習をやめる」を押すとタイトル画面に戻る |
| 1分 / 3分 | カウントダウン式。残り 10 秒以下でタイマーが点滅。3分では残り 1 分・30 秒で通知を表示 |
| 時間切れ後 | タイマーが 0 になった後も、表示中の問題に 20 秒間答えられます。正解すればその時点で終了。20 秒過ぎると「時間切れ」で終了し、その問題の経過時間も平均正解時間に算入されます（最後に素早く答えて待つことによる平均時間の操作を防ぐため。正解数にも 1 加算されます） |
| チャレンジ | タイマーは経過時間のカウントアップ。コンボゲージが切れた時点で即終了（タイトル画面に「コンボが切れたら即終了！」と表示） |

## 段位

平均正解時間（秒）と、モードごとの基準時間 timeB から段位を決めます。

```
係数 = ceil( sqrt(平均正解時間 ÷ timeB × 400) − 20 ) + 段位ペナルティ
```

- 係数 ≤ 0 → 皆伝
- 係数 1〜20 → 十段, 九段, …, 初段, 1級, 2級, …, 10級（20 以上は 10級）
- 正解 0 問 → 10級

| モード / 範囲 | timeB（NORMAL） | timeB（HARD） |
| --- | --- | --- |
| アンサー / 一次関数 | 4.0 | 4.4 |
| アンサー / 比例 | 2.5 | 2.5 |
| コネクト / 一次関数 | 2.5 | 3.0 |
| コネクト / 比例 | 1.5 | 2.0 |

### 段位ペナルティ

- コネクトモードのタップ警告 1 回につき +1
- チャレンジで正解数が少ない場合：1 問以下 +15、2 問 +10、3〜9 問 +（10 − 正解数）

### 段位の記号

| プレイ時間 | 記号 |
| --- | --- |
| 1分 | なし |
| 3分 | 最大コンボ 50 以上で「★」、それ以外は「＋」 |
| チャレンジ | 正解数 50 以上で「★」、25 以上で「＋」 |

HARD モードでは段位の前に「HARD」が付きます（例：`HARD 三段＋`）。

## ハイスコア

- `localStorage` のキー `hs_{mode}_{range}_{timeLimit}`（例：`hs_connect_linear_60`、`hs_answer_proportion_challenge`）ごとに最高スコアを保存し、リザルト画面に BEST として表示します。
- HARD モードはキーの末尾に `_hard` を付けて（例：`hs_connect_linear_60_hard`）、NORMAL とは別に保存します。

## 傾きを読み取る練習（ヘルプ → 傾きを読み取る練習）

※ タイトル画面のプレイ時間「練習」とは別の機能です。

- 一次関数のグラフ上に、切片 `(0, b)` と、そこから「右に 分母、上（下）に 分子」進んだ点を矢印つきで表示し、傾きを答えます。
- 入力はアンサーモードと同じボタン（`x` の代わりに「ヒント」）。ヒントは「傾きは 縦/横 で求めるよ！」と、右上がり／右下がりから傾きの正負を示すポップアップです。
- 正解で「正解！」（1.5 秒）、不正解で「不正解！」（0.7 秒、入力はクリア）。
- 10 問正解で「練習完了！」と表示し、ヘルプの練習ページに戻ります。「終了」ボタンでいつでも中断できます。

## サウンド

効果音（ボタン操作、カウントダウン、START、正解、不正解、点の配置・消去、リザルト）はすべて Web Audio API で生成しています。タイトル画面右上の「♪ ON / OFF」で切り替えられます（設定は保存されません）。
